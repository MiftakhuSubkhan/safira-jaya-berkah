# Safira Jaya Berkah Parking - Landing Page

Modern, pixel-perfect, responsive Next.js (App Router) landing page for **Safira Jaya Berkah Parking** (Smart Parking Management System).

## 🚀 Tech Stack
- **Framework**: Next.js 15 (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + custom high-fidelity SVG brand marks
- **Typography**: Plus Jakarta Sans & Caveat (Google Fonts)

## 📌 Features & Sections
1. **Header / Navbar**: Brand logo, navigation menu ("Beranda", "Tentang Kami", "Fitur", "Paket Kerjasama", "Kontak"), and Emerald WhatsApp button (`087844461289`).
2. **Hero Section**: Badge "SMART PARKING MANAGEMENT SYSTEM", bold copy, dual CTA buttons, 4 value metrics (Otomatis, Aman, Efisien, Modern), and interactive Smart Barrier Gate + LPR preview mockup ("B 1234 KZ - Akses Diterima").
3. **Fitur Unggulan (4 Cards Grid)**:
   - `01 Manless Gate Dispenser`
   - `02 Multi-Bank E-Money Reader`
   - `03 Fastlane Exit`
   - `04 Mobile Handheld POS`
4. **Kemitraan Strategis (3 Pricing Models)**:
   - `Management Fee` (Tech Blue button)
   - `Profit Share` (Cyan button)
   - `Guaranteed Income` (Featured with "Paling Populer" badge & Emerald Green button)
5. **Dashboard Real-Time**: Left feature highlights + Right dashboard UI preview (Total Pendapatan Rp 17.850.000, 3.482 Kendaraan, 78% Okupansi, interactive revenue spline chart, circular gauge, and In/Out traffic counters).
6. **Bottom CTA Banner**: Gradient banner with "Hubungi Kami Sekarang Juga!" and full-width WhatsApp CTA.
7. **Footer**: Brand summary, Navigasi, Layanan, Hubungi Kami (Phone: 087844461289, Sleman Yogyakarta), social media icons, and copyright.
8. **Floating WhatsApp Widget**: Quick conversion trigger button on the bottom right.

## 🛠️ How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
